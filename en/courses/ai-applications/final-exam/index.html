Exam guidance

Exam format and provided materials

The final is a 60-minute code interpretation exam with handwritten answers. A 1-page exam reference sheet is provided so you can look up the necessary syntax and relationships and apply them to the problem conditions.

You complete key parts of provided code and interpret intermediate tensor values, shapes and predictions. The exam does not require writing an entire long program or memorizing complete code.

Do not run Colab or AI during the exam. Follow the in-class exercise announcements for the exam date, location, and final procedures.

Unless otherwise specified, answers may remain as fractions, radicals or symbolic expressions. Equivalent expressions and code with the same behavior are accepted.
