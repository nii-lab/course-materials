1. Inputs, Outputs and the Feedback Path

Even for the same system, a transfer function depends on the chosen input and output. Distinguish reference tracking from disturbance rejection, and identify the signal actually measured by the sensor.

After expressing the signal relationships as equations, check that the MATLAB feedback call represents the same block connections. The error used to assess whether the actual output follows the reference can differ from the comparison signal received by the controller, depending on the sensor path.

  • Think about changing the motor voltage and changing its load. Which inputs and outputs would help you describe the motor’s behavior in each situation?

    Week 10 · Symbols and direction of motion

  • Locate the actual motor speed and the voltage sent by the sensor in the block diagram. If you vary sensor gain, what changes would you investigate in the relationship between the signals and in the response, and which outputs would you inspect?

    Week 14 · Error definitions with non-unity feedback

2. Gain Changes and Sensitivity

Gain magnitude and sensitivity to gain changes answer different questions. Closed-loop gain describes how much an input is transmitted to the output. Normalized sensitivity describes how a small relative change in a parameter is transmitted to a relative change in the result.

A sensitivity-based estimate uses the slope near a reference point. Comparing it with a value obtained by substituting the changed parameter into the original expression helps reveal the approximation’s useful range. A conclusion from a static amplifier model does not automatically extend to oscillation or stability in a dynamic system.

  • For the Week 9 amplifier, compare the goals “I want greater amplification” and “I want less output variation when component values change.” What would you vary and compare for each goal?

    Week 9 · Interpreting the results

  • Consider an experiment that varies amplifier gain. How would you choose change sizes and comparison results to investigate whether a prediction for a small change also holds for a larger one?

    Week 9 · Comparing exact changes and approximations

3. Response Speed, Oscillation and Final Value

Rise time, settling time and overshoot describe different features of a response. Reaching the target region quickly does not necessarily mean settling quickly or having a small final error. Read a graph together with its input magnitude, initial and final values, and the measurement definition of each metric.

Damping ratio and natural frequency in the standard second-order form connect poles with oscillation and response speed. Read the MATLAB step plot and stepinfo results as two descriptions of the same response. When checking a final value using dcgain, confirm that you are considering a stable model’s unit-step response.

  • Look separately at the initial rise of a response and the interval in which it stays near its final value. What would you compare if “make it faster” refers to one interval rather than the other?

    Week 11 · Definitions of response metrics

  • Choose a Week 12 response curve and sketch a version with less oscillation. Which model value would you vary to explore that change? What would reveal whether response speed changes as well?

    Week 12 · Comparing one parameter at a time

4. P/PI Control and Steady-State Error

Steady-state error is the difference between the reference and output that remains as time tends to infinity. Before discussing its value, identify closed-loop stability, the input and the definition of error. The last sample of a finite-duration plot is not automatically the limiting value.

P and PI control can produce different poles and error characteristics for the same plant. Interpret integral action together with transient response and stability, rather than final error alone. When comparing a theoretical error with simulation results, also check the input type and observation interval.

  • Consider choosing between P and PI control for the same plant from the exercise. Besides closeness to the reference, which response features would you examine, and how would you choose gains to compare?

    Week 13 · P and PI control on the same plant

  • At the end of a simulation, the output is still away from the reference. Which parts of the graph and which model values would you examine to distinguish incomplete settling from a persistent difference?

    Week 13 · Finite-time error and limiting values

5. Stability and Performance Indices

Check stability before comparing performance. For the continuous-time proper transfer functions used in these exercises, BIBO stability is checked from the poles after cancellation. Pole calculation and the Routh criterion approach the same stability question in different ways. A plausible short-duration plot alone does not establish long-term behavior.

IAE accumulates error magnitude; ISE puts greater weight on large errors; ITAE puts greater weight on errors that remain late. When forming an error from the output of lsim and integrating it with trapz, keep the input, time interval and time spacing consistent. A finite-interval value describes that interval.

  • Suppose you are comparing the Week 14 responses for different gains. Are there models you would exclude before comparing performance? Consider a selection criterion using both the pole list and the time response.

    Week 14 · Checking response stability first

  • Think of a response with a brief large deviation and another with a small persistent deviation. Which behavior would you most want to avoid in your chosen device, and which performance index would help compare that difference?

    Week 14 · Comparing performance indices over the same interval

6. Do the Model, Calculation and Plot Describe the Same Conditions?

When equations and numerical results disagree, check input magnitude and sign, coefficient order, initial conditions and the time axis before treating either result as authoritative. A reduced-order approximation does not preserve every behavior of the original model; the input, time interval and comparison quantity matter.

  • Suppose you want to reproduce an exercise response plot later. Which information about the model, input and time axis would you keep alongside it?

    Week 11 · Recording design evidence in a table

  • Place the Week 14 original and reduced-order responses on the same axes. When judging whether the models are “similar,” which parts of the response would you examine beyond the final value?

    Week 14 · Conditions for optimization and reduced-order approximation
